# KI-Support-Ticket-Klassifikation
Das System ist ein produktionsreifes, modulares Backend-Infrastruktur-Paket, das unstrukturierte, einlaufende IT-Support-Tickets (JIRA-API) vollautomatisch und in Echtzeit analysiert, thematisch über Machine-Learning-Modelle sortiert und schlüsselfertig für Business-Intelligence-Auswertungen (Power BI) in relationalen SQL-Datenbanken bereitstellt.
